Build a modern, simple **Mini Project Task Tracker** web app for people managing small projects such as study plans, college events, personal goals, side projects, or work initiatives.

### Core Goal

Users should be able to create a project, break it into tasks, track progress, and quickly understand whether the project is on track.

### 1. Project Creation

Allow users to create a project with:

* Project name
* Short description
* Scope / objective
* Start date
* Target completion date
* Expected outcome
* Optional project category

Show each project as a clean card with progress percentage, deadline, and task summary.

### 2. Task Management

Each task should have:

* Task name
* Description/notes
* Status: **To Do, In Progress, Completed**
* Priority: **Low, Medium, High**
* Due date
* Optional assignee
* Project association

Allow users to:

* Add, edit, delete and duplicate tasks
* Mark tasks completed directly from the task list
* Filter by status, priority and due date
* Sort by priority, due date and status
* Search tasks

### 3. Dashboard

Create a visually clean dashboard showing:

* Total tasks
* Completed tasks
* In-progress tasks
* Overdue tasks
* Completion rate %
* Tasks due today
* Tasks due this week
* Project progress

Include a simple progress chart and an **Overdue Tasks** section that clearly highlights tasks requiring attention.

### 4. Important Logic & Edge Cases

* A completed task should never appear as overdue.
* A task becomes overdue only when its due date has passed and it is not completed.
* Handle projects/tasks with no due date.
* Prevent invalid dates such as an end date before the start date.
* Completion rate should handle projects with zero tasks without showing NaN/errors.
* If a task is completed after its due date, retain its original due date but mark it as completed, not overdue.
* Confirm before permanently deleting projects or tasks.
* Empty states should provide helpful prompts such as “Add your first task.”
* Make the app usable on both desktop and mobile.

### 5. UI/UX

Keep the interface extremely easy to understand for a non-technical user.

Use:

* Clean modern SaaS-style design
* Minimal navigation
* Clear typography and spacing
* Cards, progress bars and subtle status indicators
* Consistent icons
* Responsive layout
* Light mode by default
* Avoid unnecessary animations, complicated menus or excessive information

Main navigation:
**Dashboard | Projects | Tasks**

Project detail page should show:
**Project Overview → Progress → Tasks → Scope & Expected Outcome**

### 6. Data & Reliability

Persist all projects and tasks so data remains after refreshing the browser. Include sensible validation, error handling, loading states and confirmation dialogs.

Build the application as a polished, production-quality MVP rather than a complicated enterprise task-management system. Prioritize **simplicity, speed and clarity**.
